# Python 開發環境專案

由 OpenClaw 協助建立的完整 Python 開發環境 🐻

## 環境設定
- **Python 版本**: 3.9.6
- **虛擬環境**: venv
- **編輯器**: Visual Studio Code
- **套件管理**: pip

## 已安裝的套件
1. **資料科學**: pandas, numpy, matplotlib
2. **網頁開發**: requests, flask
3. **自動化**: selenium, beautifulsoup4
4. **工具**: jupyter, ipython

## 專案結構
```
python_project/
├── src/           # 原始碼目錄
├── tests/         # 測試檔案
├── data/          # 資料檔案
├── notebooks/     # Jupyter Notebooks
├── requirements.txt  # 套件清單
└── README.md      # 說明文件
```

## 使用方法
```bash
# 啟動虛擬環境
source venv/bin/activate

# 安裝套件
pip install -r requirements.txt

# 啟動 Jupyter Notebook
jupyter notebook

# 執行 Python 腳本
python src/main.py
```
