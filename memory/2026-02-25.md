## 每日美股新聞 HTML 生成流程（2026-02-25 記錄）

### 任務目標

### 執行指令
```bash
cd ~/.openclaw/workspace && python scripts/generate_enhanced_news.py deploy
```

### 數據來源
1. **新聞**：使用 web_search 工具搜尋 "US stock market news [日期]"
2. **股價**：使用 yfinance 抓取即時數據
3. **指數**：^GSPC (S&P 500), ^IXIC (納斯達克), ^DJI (道瓊), ^VIX (恐慌指數), ^RUT (羅素2000)
